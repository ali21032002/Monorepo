# Mentora Documentation

Welcome to the Mentora documentation! This documentation covers the LangExtract system, API services, and related tools.

## Overview

Mentora is a comprehensive system for extracting entities and relationships from text using local LLMs (Ollama). The system includes:

- **Backend Service**: FastAPI service for text extraction and analysis
- **Frontend**: React-based UI for visualization
- **Speech-to-Text Service**: Hybrid Persian models for speech recognition
- **CLI Tools**: Command-line interface for extraction
- **LangExtract Core**: Shared Python package for extraction logic

## Features

- ✅ Entity and relationship extraction from Persian and English text
- ✅ Integration with Ollama local LLMs
- ✅ Multi-model analysis with agreement scoring
- ✅ Speech-to-text conversion with hybrid models
- ✅ Interactive chat interface
- ✅ File upload and processing
- ✅ Comprehensive API documentation
